# Context Axioms

1. **Context is compiled, not accumulated blindly.** Long context is a scarce execution resource.
2. **Stable prefix is valuable.** Keep QDW doctrine and stable tool contracts byte-stable inside a session where practical to preserve provider prompt caches.
3. **Authority is visible.** Canonical QDW contracts outrank memories and summaries.
4. **Every fragment has provenance.** No anonymous blob enters a compiled pack.
5. **Absence is explicit.** Missing relevant evidence is reported as a dropped/gap item, not silently represented as “none”.
6. **Retrieval is measurable.** Log fragments selected, fragments dropped, token estimate, compile policy/version and downstream verified outcome.
7. **Memory cannot self-promote.** Hindsight/GBrain/LCM results remain candidate context until QDW evidence promotes an invariant/standard.
8. **Failures survive.** Negative results are useful context and must not be summarized away as success.
9. **Handover before overflow.** The system should prepare continuity before a context window is forced to compress.
10. **Benchmark the context, not just the model.** `(model, tools, context_pack)` is the empirical agent configuration.
