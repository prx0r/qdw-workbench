### Key architectural decisions
1. **One shared graph** — all studios (bittensor, metaculus, etc.) write to same HydraDB instance
2. **Studio isolation via node properties** — `Run {studio: "bittensor"}` not separate graphs
3. **Immutable graph** — every write creates new subgraph, updates = new nodes + edges
4. **Separate repos as modules** — workerkit, mwgym, oracle are domain adapters that plug into private-lab
5. **CG stays separate** — evolution kernel, plugs in via adapters
