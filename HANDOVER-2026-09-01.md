**HydraDB Cypher constraints (critical):**
- Only `CREATE (a)-[:EDGE]->(b)` works (creates both nodes + edge)
- `MERGE`, standalone `CREATE`, `MATCH + CREATE` all FAIL
- Node `id` must be integer (`hash_id()` converts strings)
- `RETURN n.property` not `RETURN n`
- `count(*)` not `count(n)`
- `WITH` does not support aggregation (use Python instead)

## Architecture (frozen)

```
                    PRIVATE LAB
                         │
         ┌───────────────┼────────────────┐
         │               │                │
         ▼               ▼                ▼
     MarketOracle       /bitt         other modules
         │               │
 external jobs       internal oracle
         │               │
         └──────┬────────┘
                ▼
          POOL MATCHER
                │
           Capability Pools
                │
                ▼
          Lab intelligence
```

- Modules own their ecosystems
- Private Lab receives standardized status (not raw internal state)
- Capability Pools bridge cross-module knowledge
- Three levels: Program → Campaign → Run
- Two Oracles: MarketOracle (external) + ModuleIntelligence (internal)
